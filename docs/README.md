# WKND Migration Documentation

Analysis, outcome, and governance docs for the WKND → Edge Delivery Services migration.

## Structure

- **[pre-migration-analysis/](./pre-migration-analysis/README.md)** — discovery &
  planning done before the migration (assessment, template catalog).
- **[post-migration-analysis/](./post-migration-analysis/README.md)** — outcome
  reports after the migration (leadership summary, reusability audit, dynamic rendering).
- **[standalone/](./standalone/)** — self-contained, styled HTML versions of the reports
  (embedded dark-theme CSS, no site chrome). Open these for a clean report view — see the
  htmlpreview links below.
- **[block-governance.md](./block-governance.md)** — ongoing block-library governance
  (naming, versioning, add/modify process, SEO/a11y standards). Not a migration report,
  so it sits at the root.
